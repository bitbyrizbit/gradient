# gradient

Following the gradient: a first-principles path through computer systems, mathematics, and AI/ML engineering.

## Philosophy
This repo tracks descent, not arrival - small, first-principles steps toward genuine understanding, not memorized facts, not tutorial-following, not a leetcode-solution dump.

Every concept here is derived, not just defined: what problem existed before it, what was tried, why that failed, what this fixed and what it costs in return. If a folder just says "I read X and it says Y," that's not this repo's model. Work here should show understanding, not information.

## Navigation
- `roadmap.md` - the full phase-by-phase learning map (systems, math, ML, deep learning, specialized domains, production engineering, research skill). Consulted phase by phase, not read straight through.
- `resources.md` - a curated reference library mapped to the same phases. Used just-in-time, never worked through linearly.
- Numbered folders (`00-...`, `01-...`, etc.) - one per phase. Each has a short `README.md` (what/why), `notes.md` (concepts explained in my own words), an `experiments/` or `projects/` folder (actual code), and sometimes `takeaways.md` (real-world application, what I misunderstood and fixed).

## What this repo is not
Not a leetcode-solution archive, not a tutorial-clone collection, not a place for content that already exists better elsewhere. It exists to show depth of understanding, engineering ability, and research-level thinking, not completion count.
