# External Resources & Reference Library

Companion to `roadmap.md`. This is a reference, not a checklist — go to the relevant phase section only when that phase becomes active. Built from a strong existing library the user compiled, restructured against the 19-phase roadmap, with gaps filled in (networking, security/responsible AI, research-paper skill, a few missing classics).

**Usage philosophy (kept from the original, it's correct):**

- **Just-in-time**, not just-in-case — use a resource when its phase is active, not before.
- **Depth over breadth** — ten resources mastered beats a hundred skimmed.
- **Projects first** — resources fill gaps; they never replace building something.
- **Official > community**: docs → university courses → papers → textbooks, in that order, before blogs/YouTube summaries.
- **Deliberately excluded**: random Medium/GFG/Analytics Vidhya/Towards Data Science posts, mega "1000 free books" dumps, course-piracy links. If it dates fast or is SEO content, it's not here.

### Phase 0 — Computer Fundamentals

- **Harvard CS50** — [https://cs50.harvard.edu/](https://cs50.harvard.edu/) — the best CS intro that exists; builds computational thinking, not syntax.
- **OSTEP (Operating Systems: Three Easy Pieces)** — [https://pages.cs.wisc.edu/\~remzi/OSTEP/](https://pages.cs.wisc.edu/~remzi/OSTEP/) — free, standard OS text; use now for the memory/process basics, come back deeper in Phase 3.

### Phase 1 — Programming as a Craft

- **Official Python Docs** — [https://docs.python.org/3/](https://docs.python.org/3/) — always the first source, never a blog.
- **Real Python** — [https://realpython.com/](https://realpython.com/) — OOP, decorators, generators, typing, concurrency, done properly.
- **PEPs** — [https://peps.python.org/](https://peps.python.org/) — why Python behaves the way it does, once basics are solid.
- **MIT "Missing Semester"** (added) — free, YouTube — the best resource for Git-as-a-graph, shell, and general tooling literacy.

### Phase 2 — Data Structures & Algorithms

- **NeetCode Roadmap** — [https://neetcode.io/roadmap](https://neetcode.io/roadmap) — best interview-prep DSA path.
- **Striver's A2Z DSA Sheet** — [https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/) — most structured ground-up progression.
- **CP-Algorithms** — [https://cp-algorithms.com/](https://cp-algorithms.com/) — reference depth beyond interviews.
- **VisuAlgo** — [https://visualgo.net/](https://visualgo.net/) — visual/interactive intuition for trees, graphs, sorting, heaps.

### Phase 3 — Operating Systems & Databases

- **OSTEP** (again, deeper this time) — scheduling, virtual memory, deadlocks, concurrency.
- **CMU 15-445 — Database Systems** — [https://15445.courses.cs.cmu.edu/](https://15445.courses.cs.cmu.edu/) (Andy Pavlo) — gold standard on how databases actually work internally.
- **Full Stack Open** — [https://fullstackopen.com/en/](https://fullstackopen.com/en/) — APIs, backend, databases, testing.
- **System Design Primer** — [https://github.com/donnemartin/system-design-primer](https://github.com/donnemartin/system-design-primer) — scalability, distributed systems, interview prep.

### Phase 4 — Networking *(added — not in the original library)*

- **"High Performance Browser Networking" by Ilya Grigorik** — free online — the best "why" book for networking.
- **Hussein Nasser (YouTube)** — backend engineer explaining TCP/UDP, sockets, proxies with real system-design reasoning.
- **PowerCert Animated Videos (YouTube)** — short, visual OSI/TCP-IP model explainers.

### Phase 5 — APIs, Backend Architecture & Auth

- **Full Stack Open** (again) — practical REST/backend build-out.
- **FastAPI official docs** — [https://fastapi.tiangolo.com/](https://fastapi.tiangolo.com/) — the standard for serving Python ML/AI backends; read the docs, not a tutorial video.
- **Hussein Nasser** (again) — API/backend architecture reasoning.

### Phase 6 — Full-Stack, DevOps, Cloud & Distributed Systems

- **Docker** — [https://www.docker.com/](https://www.docker.com/) | **Kubernetes** — [https://kubernetes.io/](https://kubernetes.io/) — official docs first.
- **System Design Primer** (again) — distributed systems trade-offs.
- **"Designing Data-Intensive Applications" by Martin Kleppmann** (added) — the single best book for *why* backend/data systems are shaped the way they are; covers CAP theorem, replication, partitioning better than anything else.
- **ByteByteGo (YouTube)** (added) — sharp, visual system-design breakdowns (caching, load balancing, CAP theorem).

### Phase 9 — Classical Machine Learning

Recommended order: **Andrew Ng ML Specialization** → **Microsoft ML for Beginners** → **ISLP** → *projects* → **ESL** → **Understanding Machine Learning** → papers.

- **Andrew Ng — ML Specialization** — [https://www.coursera.org/specializations/machine-learning-introduction](https://www.coursera.org/specializations/machine-learning-introduction) — primary structured course, don't skip for a textbook.
- **Microsoft ML for Beginners** — [https://github.com/microsoft/ML-For-Beginners](https://github.com/microsoft/ML-For-Beginners) — project-based, notebook-driven.
- **ISLP** — [https://www.statlearning.com/](https://www.statlearning.com/) — the best first ML textbook, free PDF, Python edition.
- **ESL** — [https://web.stanford.edu/\~hastie/ElemStatLearn](https://web.stanford.edu/~hastie/ElemStatLearn) — advanced companion to ISLP; only after ISLP.
- **Understanding Machine Learning** — [https://www.cs.huji.ac.il/\~shais/UnderstandingMachineLearning/index.html](https://www.cs.huji.ac.il/~shais/UnderstandingMachineLearning/index.html) — PAC learning, VC dimension, learning theory; Masters-prep territory.
- **Stanford CS229** — [https://cs229.stanford.edu/](https://cs229.stanford.edu/) — full mathematical derivations, after Andrew Ng.
- **Foundations of Machine Learning (Mohri et al.)** — [https://cs.nyu.edu/\~mohri/mlbook/](https://cs.nyu.edu/~mohri/mlbook/) — rigorous theory, pairs with ESL/Understanding ML.
- **Hands-On ML (Géron)** — practical sklearn/TF/Keras engineering, late-ML-phase.
- **PRML (Bishop)** and **Probabilistic ML (Murphy)** — [https://probml.github.io/pml-book/](https://probml.github.io/pml-book/) — advanced/research-phase references, pull chapters as needed, don't read cover to cover.

### Phase 10 — Deep Learning Core

- **DeepLearning.AI** — [https://www.deeplearning.ai/](https://www.deeplearning.ai/) — industry-standard course platform.
- **Dive into Deep Learning (D2L)** — [https://d2l.ai/](https://d2l.ai/) — best implementation-first, code+math-rigorous resource.
- **Neural Networks and Deep Learning (Nielsen)** — [http://neuralnetworksanddeeplearning.com/](http://neuralnetworksanddeeplearning.com/) — best first-principles backprop intuition, read before Goodfellow.
- **Deep Learning (Goodfellow/Bengio/Courville)** — [https://www.deeplearningbook.org/](https://www.deeplearningbook.org/) — the classic, advanced-phase text.
- **Understanding Deep Learning (Prince)** — [https://udlbook.com/](https://udlbook.com/) — modern successor to Goodfellow, strong visual intuition.
- **Andrej Karpathy — Neural Networks: Zero to Hero** — [https://karpathy.ai/zero-to-hero.html](https://karpathy.ai/zero-to-hero.html) — build backprop, autograd, tokenization, and a GPT by hand. Arguably the single best resource for exactly the derive-don't-memorize approach you want.
- **FastAI** — [https://course.fast.ai/](https://course.fast.ai/) — top-down, practical complement after D2L.

### Phase 11 — Computer Vision

### Phase 14 — Generative AI Beyond LLMs

- **Probabilistic ML: Advanced Topics (Murphy)** — [https://probml.github.io/pml-book/](https://probml.github.io/pml-book/) — covers deep generative models/diffusion, the most current encyclopedic reference.
- **3Blue1Brown / Computerphile GAN & diffusion explainers** (added) — visual intuition before touching a paper.

### Phase 15 — Recommenders, Time Series, Reinforcement Learning

- **David Silver's RL Course (DeepMind)** (added) — free, YouTube — the canonical derivation-first RL course. Especially relevant if agent/LLM post-training work (Anthropic/OpenAI-style) is a direction of interest.

### Phase 16 — MLOps & Production Engineering

- **FastAPI, Docker, Kubernetes** (docs, as above) — serving infrastructure.
- **ONNX** — [https://onnx.ai/](https://onnx.ai/) — interoperable model formats.
- **TensorRT** — [https://developer.nvidia.com/tensorrt](https://developer.nvidia.com/tensorrt) | **CUDA Docs** — [https://docs.nvidia.com/cuda/](https://docs.nvidia.com/cuda/) — inference optimization, GPU fundamentals underneath every framework.
- **Machine Learning Systems** — [https://mlsysbook.ai/](https://mlsysbook.ai/) (Vijay Janapa Reddi et al., Harvard CS249r) — the missing layer between "I trained a model" and "it serves traffic reliably at scale."
- **"Designing Machine Learning Systems" by Chip Huyen** (added) — best production-ML book, written exactly in the why-did-it-break/what-fixed-it style.
- **Made With ML** (added) — madewithml.com — excellent free, practical MLOps walkthrough.

### Phase 17 — AI Security, Responsible AI & Explainability *(added — not in the original library)*

- **Anthropic Research** — [https://www.anthropic.com/research](https://www.anthropic.com/research) — genuinely the best primary source for current alignment/interpretability/safety thinking, directly relevant if a lab like this is a goal.
- **"Interpretable Machine Learning" by Christoph Molnar** — free online book — SHAP/LIME/explainability depth.

### Phase 18 — Research Skills

- **System Design Primer** (again) — dual-purpose: interview prep and before any Masters/research cycle.
- **"How to Read a Paper" by S. Keshav** (added) — short free PDF — the actual method, not vague advice.
- **Yannic Kilcher (YouTube)** (added) — paper walkthroughs explaining *why* a paper's idea works.
